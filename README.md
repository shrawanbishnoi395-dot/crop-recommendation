# 🌱 Intelligent Crop Recommendation System

This is an end-to-end Machine Learning project that predicts the most suitable crop to cultivate based on soil nutrients and climate parameters.

### 🚀 Live Demo
You can test the live application here: [Click Here to View the Live App](https://crop-recommendation-9.streamlit.app/)

## 🛠️ Tech Stack
* **Frontend:** Streamlit
* **Machine Learning:** Scikit-Learn, Pandas, NumPy
* **Deployment:** Streamlit Cloud
